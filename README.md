# come-come

食べている様子をカメラで映しておくだけで、**何カロリー摂取したか**、**どの栄養素が足りていて何が足りていないか** を自動で計算する Web アプリです。

## しくみ

1. ブラウザでカメラ映像を取得し、一定間隔(5〜30秒)で静止画を切り出します。映像にほとんど変化がなければ解析を飛ばして API 呼び出しを節約します。写真を撮って(選んで)解析することもできます。
2. サーバーが画像を Claude に送り、料理を**食材ごとに分解**して、各食材の重さ(g)と現在の残量(%)を構造化 JSON で受け取ります。量は茶碗・箸・皿など画像内の基準物から見積もらせます。
3. 栄養素は、食材が `public/foods.js` の成分表(日本食品標準成分表(八訂)などを参考にした概算値)にあれば**表の値 × グラム数**で計算し、表に無い食材だけ AI の推定値を使います。
4. 動画の物体追跡と同じ考え方で、結果を平滑化します。
   - 新しい料理は「確認中」で追加し、もう一度映るか信頼度が高いときだけ記録します(誤検出対策)。
   - 残量は直近3回の中央値で外れ値を除き、さらに減る方向にしか更新しません(二重計上防止)。
   - 新しい食事の最初の1枚は推論を深く(`high`)、以降の残量の更新は軽く(`low`)します。
5. 1日の合計を、性別・年齢・身体活動レベルから求めた目標量(日本人の食事摂取基準を簡略化)と比べ、「不足/適量/過剰」と、不足分を補う食品の例を表示します。
6. 推定が外れたときは、食べた量のスライダー、量の補正(×0.5〜×2)、確定・削除で直せます。

記録はブラウザの localStorage に日付ごとに保存されます。

計算する栄養素: エネルギー、たんぱく質、脂質、炭水化物、食物繊維、食塩相当量、カルシウム、鉄、ビタミンA・B1・B2・C・D

## プレビュー(claude.ai 上で動く版)

`npm run build:preview` で `dist/preview.html` を作れます。claude.ai の Artifact として公開すると、閲覧者自身の Claude で解析するため、サーバーや API キーなしで試せます。claude.ai 上ではカメラ API が使えないため、プレビューでは「写真を撮って解析」(スマホではカメラが起動)で使います。

## 使い方

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start
# → http://localhost:3000 を開いて「カメラ開始」
```

スマートフォンから使う場合、カメラは HTTPS(または localhost)でしか動かないため、HTTPS のリバースプロキシやトンネル経由で公開してください。

- **食事を区切る**: 次に映った料理を新しい食事として扱います(朝食→昼食など)。
- **完食 / 削除**: 推定を手動で補正できます。
- **プロフィール**: 目標量の計算に使う性別・年齢・活動レベルを設定します。

### 環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | – | Claude API キー |
| `PORT` | `3000` | 待ち受けポート |
| `COMECOME_MODEL` | `claude-opus-5` | 解析に使うモデル |
| `COMECOME_EFFORT` | `low` | 残量を更新するときの推論の深さ(`low`〜`max`)。上げると精度↑・遅延とコスト↑ |
| `COMECOME_INITIAL_EFFORT` | `high` | 新しい食事の最初の1枚(料理と量の特定)の推論の深さ |

## 注意

数値は画像からの AI 推定値で、目標量は成人向けの簡略化した目安です。医療・栄養指導の代わりにはなりません。
