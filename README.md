# come-come

食べている様子をカメラで映しておくだけで、**何カロリー摂取したか**、**どの栄養素が足りていて何が足りていないか** を自動で計算する Web アプリです。

## しくみ

1. ブラウザでカメラ映像を取得し、一定間隔(5〜30秒)で静止画を切り出します。映像にほとんど変化がなければ解析をスキップして API 呼び出しを節約します。
2. サーバーが画像を Claude(ビジョン)に送り、映っている料理・1人前の栄養素量・現在の残量(%)を構造化 JSON で受け取ります。
3. 「配膳時の量 − 現在の残量」を食べた量として栄養素を積算します。残量は減る方向にしか更新しないので、箸で持ち上げた・角度が変わった等で推定がぶれても二重計上しません。
4. 1日の合計を、性別・年齢・身体活動レベルから求めた目標量(日本人の食事摂取基準を簡略化)と比べ、「不足/適量/過剰」と、不足分を補う食品の例を表示します。

記録はブラウザの localStorage に日付ごとに保存されます。

計算する栄養素: エネルギー、たんぱく質、脂質、炭水化物、食物繊維、食塩相当量、カルシウム、鉄、ビタミンA・B1・B2・C・D

## 使い方

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start
# → http://localhost:3000 を開いて「カメラ開始」
```

スマートフォンから使う場合、カメラは HTTPS(または localhost)でしか動かないため、HTTPS のリバースプロキシやトンネル経由で公開してください。

- **食事を区切る**: 次に映った料理を新しい食事として扱います(朝食→昼食など)。
- **完食 / 削除**: 推定を手動で補正できます。
- **プロフィール**: 目標量の計算に使う性別・年齢・活動レベルを設定します。

### 環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | – | Claude API キー |
| `PORT` | `3000` | 待ち受けポート |
| `COMECOME_MODEL` | `claude-opus-5` | 解析に使うモデル |
| `COMECOME_EFFORT` | `low` | 推論の深さ(`low`〜`max`)。上げると精度↑・遅延とコスト↑ |

## 注意

数値は画像からの AI 推定値で、目標量は成人向けの簡略化した目安です。医療・栄養指導の代わりにはなりません。
