# come-come

食べている様子をカメラで映しておくだけで、**リアルタイムに**摂取カロリーと栄養素の過不足を記録する Web アプリです。
メキシコ向けを基本に(スペイン語・メキシコの食品・メキシコ/国際基準)、英語・日本語にも対応します。

## しくみ

1. **端末内のリアルタイム検出**: ブラウザ内で物体検出モデル(TensorFlow.js の COCO-SSD)を1秒に数回動かし、皿・コップ・フォーク・人を枠で表示します。フォークやコップが口元に入って出ると「ひと口」と数えます。
2. **出来事があったときだけ Claude で解析**: 料理が映ったとき、ひと口食べたとき、画面が大きく変わったときに、フレームを Claude に送ります。Claude は料理を**食材ごとに分解**し、各食材の重さ(g)と残量(%)を返します。
3. **長さ測定アプリと同じ考え方で量を測る**: 10ペソ硬貨(28mm)・カード・トルティーヤ・皿などを基準物として画像内の寸法(cm)を測り、体積と密度から重さを出します。いつもの皿の直径を設定すると、それを最優先で使います。
4. **栄養は成分表で計算**: 食材が `public/foods.js` の食品データベース(約70品。USDA や日本食品標準成分表などの公開データを参考にした概算値)にあれば、表の値 × グラム数で計算します。
5. **車両追跡と同じ平滑化**: 新しい料理は「確認中」にして2回映ったら記録し、残量は直近3回の中央値+減る方向にだけ更新します(誤検出・二重計上の防止)。

## 主な機能

- 初回起動時にプロフィール(性別・年齢・身長・体重・目標体重・活動量・目的)を入力 → 基礎代謝(Mifflin-St Jeor 式)から1日の目標カロリーを計算
- 食事区分(Desayuno / Comida / Cena / Colación)ごとの記録。時刻から自動で振り分け
- 食品検索による手入力(スペイン語・英語・日本語、アクセント記号なしでも検索可)
- 13栄養素の過不足と、不足分を補う食品の提案
- 栄養バランスの点数(100点満点)
- 体重の記録とグラフ、BMI
- 直近7日の履歴
- 栄養基準の切り替え: メキシコ(IDR / WHO)・国際(DRI / WHO)・日本(食事摂取基準)
- **ながら記録モード(プレミアム)**: 画面を暗くしてスリープさせずに食事の最初から最後まで記録し、解析間隔も短くします(無料 8 秒、プレミアム 4 秒)。現在はお試しとして設定から有効化でき、課金は未実装です。

### バックグラウンド動作について

ブラウザ(Web アプリ)は、アプリが裏に回ったり画面が消えたりするとカメラを止めます。これは iOS / Android の仕様で回避できないため、Web 版の「ながら記録モード」は「画面をつけたまま暗くして動かし続ける」方式です。画面を消した状態や他のアプリ使用中にもカメラ解析を続けるには、ネイティブアプリ化(Capacitor などでの iOS / Android アプリ化)が必要です。

## 使い方

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start
# → http://localhost:3000 を開く
```

スマートフォンで使う場合、カメラは HTTPS(または localhost)でしか動かないため、HTTPS で公開してください。

### 環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | – | Claude API キー |
| `PORT` | `3000` | 待ち受けポート |
| `COMECOME_MODEL` | `claude-opus-5` | 解析に使うモデル |
| `COMECOME_EFFORT` | `low` | 残量を更新するときの推論の深さ(`low`〜`max`) |
| `COMECOME_INITIAL_EFFORT` | `high` | 新しい食事の最初の1枚(料理と量の特定)の推論の深さ |

## プレビュー

`npm run build:preview` で `dist/preview.html` を作れます。claude.ai の Artifact として公開すると画面を試せますが、claude.ai 上ではカメラが使えないため、プレビューはサンプル表示と手入力・プロフィール・体重などの確認用です。

## 注意

数値は画像からの AI 推定値で、目標量は成人向けの一般的な目安です。医療・栄養指導の代わりにはなりません。
